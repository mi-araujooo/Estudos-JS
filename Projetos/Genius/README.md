# Genius Game (Simon Says) 🎮
Projeto de recriação do jogo **Genius (Simon Says)** desenvolvido com **HTML, CSS e JavaScript puro**, com foco em lógica de programação, controle de estado e manipulação assíncrona de eventos.

## 🛠 Tecnologias
- HTML
- CSS
- JavaScript

## 🎯 Objetivo
O Genius é um jogo de memória onde o sistema gera uma sequência de cores que o jogador deve reproduzir corretamente.  
A cada rodada, uma nova cor é adicionada à sequência, aumentando progressivamente a dificuldade.

Este projeto foi desenvolvido com o objetivo de **praticar lógica, organização de código e controle de fluxo**, sem o uso de bibliotecas externas.

## Funcionalidades ⌨️
- Geração aleatória de sequência
- Exibição da sequência com efeito de “piscar”
- Validação da jogada do jogador passo a passo
- Progressão automática de rodadas
- Detecção imediata de erro (Game Over)
- Placar de rodadas
- Feedback visual por popup (toast)
- Bloqueio de jogadas fora do momento correto
